# مسار الإطلاق — إزاي تشتغل مع Claude Code

كل مرة تفتح Claude Code في فولدر المشروع وتكتب:

```
/nextphase
```

وClaude هيعمل الآتي لوحده:

1. يجيب آخر نسخة من `main` ويشوف أنهي مرحلة عليها الدور.
2. **يعرّفك هينفذ إيه** (الهدف، اللي هيتبني، معايير القبول، والقرارات اللي محتاجها منك).
3. لو المرحلة محتاجة قرار لسه ما اتاخدش، يسألك ويسجّل إجابتك في `launch/DECISIONS.md`.
4. ينفّذ على branch جديد `claude/Pxx-...`، يشغّل الاختبارات، ويخلي 3 مراجعين (أمان، بيزنس لوجيك، تصميم) يراجعوا الشغل.
5. يفتح Pull Request ويقولك تجرّبه إزاي.

**إنت بتعمل حاجة واحدة:** تراجع الـPR وتعمل merge. المرحلة بتتحسب «خلصت» لما الـPR يتعمله merge، وبعدها `/nextphase` تاني.

## أوامر تانية

| الأمر | بيعمل إيه |
| --- | --- |
| `/nextphase preview` | يقولك المرحلة الجاية هتعمل إيه من غير ما ينفذ |
| `/nextphase fix` | يصلّح تعليقات المراجعة أو الـCI اللي فشل في الـPR المفتوح |
| `/nextphase P07` | يشتغل على مرحلة معيّنة (لو اللي قبلها خلص) |
| `/phase-status` | جدول بالمراحل اللي خلصت والجاية والقرارات المفتوحة |
| `/verify` | يشغّل كل الاختبارات ويكتب النتائج |
| `/figma-screen <node>` | يبني أو يظبط شاشة من الفيجما |

## قبل أول `/nextphase`

1. ثبّت: .NET 10 SDK، Node (نفس نسخة الـCI)، Docker، و`gh` واعمل `gh auth login`.
2. اربط الفيجما بـClaude Code: `claude mcp add --transport http figma https://mcp.figma.com/mcp` ثم سجّل الدخول لما يطلب.
3. افتح Claude Code في جذر الريبو واكتب `/nextphase`.

## ضمانات الأمان

Claude **مش هيعمل أبدًا**: merge، push على `main`، force push، نشر على سيرفر، لمس DNS أو بيانات إنتاج أو أسرار، أو تعطيل اختبار علشان يعدّي. المرحلة P16 بالذات كل خطوة فيها محتاجة «موافق» صريحة منك.

اختياري: تقدر تضيف ملف `.claude/settings.json` بقواعد منع إضافية زي دي (القرار ليك، Claude ما أضافهاش لوحده):

```json
{
  "permissions": {
    "deny": [
      "Bash(git push --force:*)",
      "Bash(git push origin main:*)",
      "Bash(gh pr merge:*)",
      "Bash(dotnet ef database:*)",
      "Read(./.env)"
    ]
  }
}
```

ولو عايز Claude ما يسألكش قبل أوامر الاختبار والبناء، ضيف قائمة `allow` بنفسك (مثلًا `Bash(dotnet test:*)` و`Bash(npm run:*)`).
